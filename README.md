# World Happiness Report 2019 - Assignment 1

## Dataset Source
The dataset was downloaded from Kaggle: [World Happiness Report 2019](https://www.kaggle.com/datasets/unsdsn/world-happiness)

## Dataset Description
The dataset contains information about happiness scores and factors affecting happiness across different countries.

### Number of rows and columns
- Rows: 156
- Columns: 9

### Features (Columns)
1. **Overall rank**: Rank of the country in terms of happiness  
2. **Country or region**: Name of the country  
3. **Score**: Happiness score  
4. **GDP per capita**: Economic output per person  
5. **Social support**: Measure of social support in the country  
6. **Healthy life expectancy**: Life expectancy adjusted for health  
7. **Freedom to make life choices**: Measure of personal freedom  
8. **Generosity**: Measure of generosity  
9. **Perceptions of corruption**: Measure of corruption in the government and business  

## Purpose of Using this Dataset
The purpose of this dataset is to perform Exploratory Data Analysis (EDA) to understand the factors affecting happiness across countries. We aim to visualize the distribution of happiness scores, analyze correlations between factors, and identify trends among different countries.
